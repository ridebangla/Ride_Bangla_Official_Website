# 📖 About Ride Bangla

**Ride Bangla** is a Bangladesh-focused digital service ecosystem built for customers, partners, riders, agents, administrators and future financial services.

This repository contains the official **Ride Bangla Website**. The website represents the public face of Ride Bangla and explains the platform vision, launch services, future roadmap, business opportunities, support information, policies and ecosystem structure.

The website is not a fake demo landing page. It is designed as the official company website for a real production ecosystem.

---

# 🎯 Website Purpose

The Ride Bangla Website is responsible for:

- Presenting the Ride Bangla brand
- Explaining active services
- Showing the future roadmap
- Providing contact and support information
- Publishing company policies
- Supporting user trust before app release
- Presenting Customer, Partner, Rider and Admin ecosystem logic
- Preparing public pages for SEO and search discovery
- Explaining business and partnership opportunities

---

# 🚀 Current Launch Focus

Ride Bangla starts with two active launch services:

| Service | Status | Description |
|---|---:|---|
| Food Delivery | Active Launch | Customers order food from approved restaurants and home kitchens. |
| Courier | Active Launch | Customers send documents or parcels through eligible riders. |

The platform is future-ready for marketplace, grocery, pharmacy, ride, rewards, business services and Ride Bangla Pay.

# 🧩 Ecosystem Applications

## 📱 Customer App

The public mobile app for customers.

Customers can:

- Create an account
- Select location in Bangladesh
- Browse food
- Place food orders
- Send courier requests
- Save addresses
- Track orders
- View offers
- Receive notifications

## 🍽 Partner App

The business app for approved partners.

Partners can manage:

- Restaurants
- Home kitchens
- Menus
- Products
- Offers
- Availability
- Orders
- Business profile
- Future marketplace products

## 🛵 Rider App

The logistics app for delivery riders.

Riders can:

- Register and verify profile
- Go online/offline
- Receive delivery requests
- Accept food and courier orders
- Pickup and deliver
- Track earnings
- Request withdrawals

## 🖥 Admin Console

The private internal control system.

Admin controls:

- Users
- Partners
- Riders
- Orders
- Offers
- Categories
- Reports
- Notifications
- Platform settings
- Future agent and finance operations

# 🤝 Agent Platform

Agent Platform is planned as a near-future expansion.

Agents may support:

- Partner onboarding

Ride Bangla Pay is planned for the future as a separate digital financial platform, not just a small internal wallet.

Future capabilities may include:

- Digital wallet
- Customer payments
- Partner settlement
- Rider earnings
- Merchant payments
- QR payments
- Bank transfer
- Visa/Mastercard support
- Cashback and rewards

Ride Bangla Pay will be a separate app/service and will integrate with the Ride Bangla ecosystem when ready.

# 🔐 Security & Privacy

The website should never expose private Firebase credentials beyond safe public environment variables required by frontend Firebase apps.

Rules:

- Do not commit private keys
- Do not expose admin credentials
- Do not store secrets in public code
- Use environment variables
- Use Firebase Security Rules
- Protect form submissions
- Validate user input

---

# ⚙️ Environment Variables

Example public environment variables:
