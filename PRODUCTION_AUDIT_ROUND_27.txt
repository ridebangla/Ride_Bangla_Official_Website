CONFIRMED FIXES
1. Bengali-only FAQ records were silently excluded.
   The Help Center UI supported bilingual fallback, but getFaqs() required the English question and answer fields. A valid Firestore FAQ containing only question_bn/answer_bn therefore disappeared. The loader now accepts question_en/question, question_bn, answer_en/answer and answer_bn, preserves bilingual values, and safely populates primary fallback fields.

2. Notification read state could lose a recently clicked ID.
   markRead() and markAllRead() used the render-time readIds closure. Rapid interactions before React committed the prior state could overwrite a newer read ID. Both actions now use functional state updates, deduplicate against the latest state and keep the 200-ID storage bound.
