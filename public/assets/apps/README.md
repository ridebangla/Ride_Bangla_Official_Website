# Ride Bangla app logo assets

Place each official app logo in this folder using the exact filename below.
The website reads these files directly; no code change is required after replacing or adding a logo.

- `customer.png` — Ride Bangla customer app
- `partner.png` — Ride Bangla Partner
- `rider.png` — Ride Bangla Rider
- `admin-console.png` — Ride Bangla Admin Console
- `agent.png` — Ride Bangla Agent
- `pay.png` — Ride Bangla Pay

Recommended production asset:

- PNG with transparent background
- Square canvas (recommended 1024 × 1024)
- Official app icon only
- Keep safe spacing around the logo
- Use the exact lowercase filename shown above

When a file is absent or cannot be loaded, the website intentionally leaves that app's logo area empty. It does not show a placeholder, initials, generic icon, or fake logo.
